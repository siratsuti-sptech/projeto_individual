## Sobre o projeto

**Tabito** (旅人) significa *viajante* em japonês. O projeto nasceu da minha vivência, nasci no Japão, cresci no Brasil e voltei a morar no Japão aos 13 anos. Dessa jornada surgiu a convicção de que **todo mundo tem algo para compartilhar com o próximo**.

O objetivo é oferecer um website com cadastro e login em que usuários possam publicar suas próprias vivências, dicas e histórias de viagem, com foco no Japão.

> Projeto individual de **Pesquisa e Inovação** do curso de Análise e Desenvolvimento de Sistemas da **SPTech**, desenvolvido em 6 semanas.

## Como executar

```bash
# 1. Clone o repositório
git clone https://github.com/siratsuti-sptech/projeto_individual.git

# 2. Entre na pasta do projeto
cd projeto_individual/tabi/web-data-viz

# 3. Instale as dependências
npm install

# 4. Configure o banco de dados (script SQL do projeto)

# 5. Inicie a aplicação
npm start
```

Depois, acesse `http://localhost:3333` (ou a porta configurada no projeto).
